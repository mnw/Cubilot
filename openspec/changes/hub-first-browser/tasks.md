One group = one ticket. Each group names its radius and its `blocked_by` with the reason; the radius rule of `config.yml` may raise a low group. The tickets do not tick this file. Each ticket that changes `hub/hub.ts` or a Kind runs `./scripts/build-sidecars.sh`; each ticket that changes `hub/channel/**` also runs `./scripts/check-mod.sh`. Each UI ticket has a browser run in `/tmp/cubilot-ui-harness`. Full suite: `./scripts/test.sh` by the Tester. Group 11 sets `caller: "human"` on the routes that exist on staging when it starts; groups 8 and 9, if they land after it, set the flag on their own routes.
