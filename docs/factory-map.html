04Mutation testing pipeline

Runs inside the technical track, on the files the ticket changed only (§13). The triage step sends code to TypeSafe through OpenRouter, so a project setting keeps it off by default.

Doctor: project checkstack from composer.json, package.json…; tool and PCOV/Xdebug present
→
Tester: mutation runInfection, StrykerJS, mutmut, PIT, cargo-mutants; JSON report
→
Tester: jtt triageJev answers 12 questions per survivoronly if mutation_triage = on
→
Bandsact · review · ignore
→
Validatoradvisory: suggestions only · enforce: open act blocks unless marked equivalent
→
Workerwrites killing tests from agent-prompt.md

Mode per project: mutation_mode: off | advisory | enforce, default off. Advisory first, to learn the real scores. Fast suites only (unit + kernel), 15-min time budget, a partial result never blocks. No jtt for PHP/Drupal → in enforce the Validator applies the project's mutation_threshold, set from the advisory results.

Data: scores and act/review/ignore counts go into the review kind, and the dashboard Quality panel shows them per code ticket (§11).

05Jev decision points

Jev returns typed answers only: a choice, a probability or a score, with no text. Code builds the state, Jev decides, code acts. Each point must beat a simple rule before it stays.
